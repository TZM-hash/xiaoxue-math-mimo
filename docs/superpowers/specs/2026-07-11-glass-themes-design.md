# 双毛玻璃主题设计

## 目标

为喵喵学习新增两个开局直接可用的系统主题：清透、克制的 `清透玻璃`，以及色彩鲜艳、卡通感更强的 `缤纷玻璃`。两个主题必须覆盖现有主要页面和弹窗，同时保持题目阅读、选项比较和按钮操作清晰。

## 主题标识

- `glass-clear`: 清透玻璃。
- `glass-pop`: 缤纷玻璃。

两个主题均加入 `THEME_REGISTRY`，标记为 `initial: true`，因此无需宠物等级或金币即可使用。主题出现在系统设置下拉框和主题商店的“开局主题”分组中。

## 清透玻璃

视觉目标是轻、透、安静，但不能变成单一蓝色界面。

- 页面背景使用冷白、浅青和薄荷绿的低饱和透明渐变。
- 允许使用大面积、低对比度的柔和光影和模糊色斑，保持轻盈通透。
- 主表面使用高透明白色，保留足够文字对比度。
- 边框使用细白边和浅青灰内描边。
- 阴影范围较大但透明度低，避免悬浮卡片显得厚重。
- 强调色使用薄荷绿，辅助色使用淡黄和少量浅蓝。
- 题干、答案输入和报告正文保持深色文字。

## 缤纷玻璃

视觉目标是鲜艳、活泼、卡通化，同时保持玻璃材质一致。

- 页面背景使用珊瑚红、明黄、湖蓝和草绿的鲜艳多色渐变。
- 使用卡通感更强的彩色光球和模糊装饰斑点，形成活泼层次。
- 主表面仍使用半透明白色，避免彩色背景影响阅读。
- 按钮、标签、进度和状态组件使用不同功能色，而不是同一色系深浅变化。
- 正确、错误、提示和奖励状态继续使用语义明确的颜色。
- 卡通感来自鲜艳配色和清晰边框，不增加复杂装饰图形。

## 毛玻璃规则

仅 `glass-clear` 和 `glass-pop` 启用明显的毛玻璃覆盖：

- 应用头部、导航、设置区、练习卡、报告区、宠物区、重复项目卡片、弹窗和悬浮面板使用半透明表面。
- 使用 `backdrop-filter: blur(...) saturate(...)` 与 `-webkit-backdrop-filter`。
- 卡片圆角继续遵循现有设计，不新增大面积药丸形容器。
- 输入框和题目选项使用更高不透明度，避免背景透色影响识别。
- 当前主题下的学科色仍可生效，但透明度和边框由玻璃主题统一控制。
- 背景渐变、光球和模糊色斑固定在页面背景层，不覆盖题干、表单和交互控件。

## 降级处理

当设备或 WebView 不支持 `backdrop-filter` 时：

- 使用更高不透明度的主题表面色。
- 保留边框和阴影层次。
- 不依赖模糊效果表达选中、禁用或错误状态。
- Android WebView 与桌面浏览器使用相同 CSS，不引入运行时检测代码。

## 主题注册与兼容

- 在所有主题下拉框中增加两个选项。
- `SYSTEM_THEME_IDS` 和默认系统主题集合自动包含两个新主题。
- 旧档案无需迁移；读取旧主题值的行为保持不变。
- 当前使用的旧主题不会被自动切换。
- 导出、导入和云端档案中使用现有主题字段保存新主题标识。

## 测试与验收

- 主题注册测试确认两个主题存在且均为开局可用。
- 布局测试确认两个主题的 CSS 令牌、毛玻璃选择器和设置选项存在。
- 浏览器测试依次切换两个主题，确认 `data-theme`、选项状态和主题持久化更新。
- 桌面与 390×844 手机视口分别截图主页、做题页和主题商店。
- 检查题干、选项、输入框、弹窗、悬浮猫咪和主要按钮没有对比度不足、裁切或重叠。
- Web 与 Android 资源保持同步。
- `npm test`、Android 同步检查和 `git diff --check` 必须通过。
