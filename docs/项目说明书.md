# 喵喵学习项目说明书

## 1. 项目简介

喵喵学习是一款面向小学阶段学生的离线优先学习练习应用。项目最初以数学练习为核心，当前已扩展为多学科练习系统，覆盖数学、语文、英语、科学，并围绕杭州市小学学生的日常练习场景设计。

应用提供：

- 按年级和知识点生成练习题。
- 多学科切换与题型设置。
- 错题本、薄弱点推荐、今日学习路线。
- 学习报告、知识地图、题库质量巡检。
- 宠物成长、奖励、任务和装扮反馈。
- Web/PWA 与 Android 离线包两种使用方式。

## 2. 目标用户

主要用户：

- 杭州市小学一至六年级学生。
- 家长或老师，用于家庭练习、错题巩固、阶段复习。

使用特点：

- 单次练习时间短，适合碎片化练习。
- 题目需要可自动判分。
- 数据应尽量保存在本地，弱化网络依赖。
- 低年级学生需要更直接的反馈和奖励机制。

## 3. 学科与内容范围

数学：

- 一至六年级。
- 覆盖加减乘除、竖式、分数、小数、百分数、图形、统计、应用题、思维阅读等。
- 题目规则由 `js/question-bank.js`、`js/question-generator.js` 与 `js/question-rules-engine.js` 共同保障。

语文：

- 一至六年级。
- 覆盖拼音、识字、词语、句子、标点、阅读、古诗文、习作与综合表达。
- 数据来源结构在 `js/chinese-curriculum-data.js` 和 `js/chinese-question-bank.js` 中维护。

英语：

- 三至六年级。
- 覆盖词汇、自然拼读、句型、语法、阅读。
- 使用 PEP 人教版小学英语能力线组织。

科学：

- 一至六年级。
- 覆盖生命科学、物质科学、地球宇宙、工程技术、科学探究。
- 面向浙江常用小学科学能力线组织。

扩展题源：

- `js/external-question-seeds.js` 维护外部参考题源 seed。
- 题目记录 `sourceMeta`，区分公开资源参考与题型结构参考后的原创改写。
- 当前测试要求数学、语文、英语、科学各至少覆盖 8 个重点知识点，并包含官方/区域来源和国内题库题型来源。

## 4. 主要功能

练习功能：

- 普通练习。
- 薄弱点练习。
- 5 分钟限时小测。
- 闯关练习。
- 错题复练。

答题与判分：

- 支持文本、数字、选择题等客观可判分答案。
- 对分数、小数、单位、选择题答案标签做归一化。
- 非数学题通过 `subject` 字段与学科题库隔离。

学习诊断：

- 根据正确率、错因、用时和错题记录生成薄弱点。
- 首页展示今日学习路线。
- 学习报告展示正确率、题型构成、节奏趋势、错因摘要。

宠物激励：

- 完成练习获得经验、亲密值、金币等奖励。
- 支持每日/每周任务。
- 支持宠物状态、成长阶段、装扮、主题商店。

数据管理：

- 使用本地存储保存用户档案、练习记录、设置和宠物状态。
- 提供导入导出能力，方便备份与迁移。
- 云同步模块存在，但应用启动不依赖 Supabase SDK，保持离线优先。

## 5. 使用入口

Web 入口：

```text

```

```text

```

```text
file:///android_asset/www/index.html
```

## 6. 项目目录说明

```text
css/                         样式、主题、动画、特效设置
js/                          Web 端业务模块和题库模块
assets/                      图标、宠物图片、音效资源
tests/                       Node 测试与浏览器冒烟测试
scripts/                     Android assets 同步与题库覆盖检查脚本
android/                     Android WebView 工程
android/app/src/main/assets/www/  Android 内置 Web 资源镜像
docs/                        项目文档
```

核心 JS 文件：

```text
js/app.js                    主应用状态、页面渲染、答题流程、奖励流程
js/question-bank.js          数学知识点与课程映射
js/question-generator.js     总题目生成入口
js/question-rules-engine.js  题目规则巡检
js/practice-engine.js        练习组卷逻辑
js/subject-registry.js       多学科注册表
js/*-question-bank.js        语文/英语/科学题库
js/*-question-generator.js   语文/英语/科学生成器
js/external-question-seeds.js 扩展题源 seed
```

## 7. 质量保障

项目当前主要通过 Node 脚本测试保证质量：

```powershell
$ErrorActionPreference = 'Stop'
npm test
```

测试范围：

- 题库结构与覆盖。
- 多学科隔离。
- 题目规则与边界。
- 外部题源来源和答案洗牌。
- 前端布局契约。
- Android assets 镜像一致性。
- 浏览器冒烟测试。

## 8. 当前限制

- 项目没有构建打包步骤，Web 端依赖脚本加载顺序。
- 题目主要为规则生成和 seed 题，不是后端题库服务。
- 本地存储容量受浏览器/WebView 限制。
- Android WebView 与桌面浏览器能力不同，涉及音频、TTS、存储时需要额外验证。
- 手写输入模块文件仍存在，但页面当前不加载全屏手写识别流程。
