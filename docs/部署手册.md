# 喵喵学习部署手册

## 1. 部署对象

本项目有两种交付形态：

- Web/PWA：以 `index.html` 为入口的静态前端应用，可直接放到静态文件服务器或本地浏览器运行。
- Android APK：原生 Android WebView 外壳，加载 `android/app/src/main/assets/www/index.html` 中的离线 Web 资源。

项目不依赖后端服务即可运行，学习记录默认保存在浏览器或 WebView 的本地存储中。

## 2. 环境要求

基础环境：

- Node.js：用于运行测试脚本。
- npm：随 Node.js 安装。
- PowerShell 7 或以上：推荐使用 `pwsh`。
- Microsoft Edge：浏览器冒烟测试默认会尝试使用 Edge。

Android 打包环境：

- JDK 17。
- Android SDK，`compileSdk` 为 34。
- Gradle Wrapper：项目已包含 `android/gradlew.bat`。

## 3. Web 本地运行

项目是静态站点，最短路径可以直接打开：

```powershell
$ErrorActionPreference = 'Stop'
Start-Process .\index.html
```

如果希望用本地 HTTP 服务预览，可在项目根目录启动一个静态服务：

```powershell
$ErrorActionPreference = 'Stop'
npx http-server . -p 5173
```

然后访问：

```text
http://127.0.0.1:5173/
```

## 4. Web 静态部署

部署 Web 版时，至少需要上传以下内容：

- `index.html`
- `manifest.webmanifest`
- `css/`
- `js/`
- `assets/`

推荐部署前执行：

```powershell
$ErrorActionPreference = 'Stop'
npm test
```

静态服务器要求：

- 保持文件相对路径不变。
- 正确返回 `.js`、`.css`、`.png`、`.wav`、`.webmanifest` 文件。
- 如果使用子路径部署，需要确认 `manifest.webmanifest` 的 `start_url` 与资源相对路径仍然可访问。

## 5. Android 资源同步

Android WebView 加载的是 `android/app/src/main/assets/www/` 下的镜像资源。修改 Web 端资源后，必须同步 Android assets：

```powershell
$ErrorActionPreference = 'Stop'
.\scripts\sync-android-assets.ps1
```

同步检查：

```powershell
$ErrorActionPreference = 'Stop'
npm run sync:android:check
```

同步脚本会复制以下资源：

- `index.html`
- `manifest.webmanifest`
- `css/`
- `js/`
- `assets/`

如果新增 Web 端资源目录，必须同时更新：

- `scripts/sync-android-assets.ps1`
- `scripts/check-android-assets.js`
- 相关布局或镜像测试

## 6. Android Debug 包构建

进入 Android 目录后执行：

```powershell
$ErrorActionPreference = 'Stop'
Set-Location .\android
.\gradlew.bat assembleDebug
```

产物位置：

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

Debug 包的 `applicationId` 会带 `.debug` 后缀。

## 7. Android Release 包构建

Release 签名配置位于 `android/app/build.gradle`。项目当前使用：

- keystore：`android/miaomiao-release.keystore`
- key alias：`miaomiao`
- 环境变量：`KEYSTORE_PASSWORD`、`KEY_PASSWORD`

推荐构建前显式设置密码环境变量：

```powershell
$ErrorActionPreference = 'Stop'
$env:KEYSTORE_PASSWORD = '<替换为实际 keystore 密码>'
$env:KEY_PASSWORD = '<替换为实际 key 密码>'
Set-Location .\android
.\gradlew.bat assembleRelease
```

产物位置：

```text
android/app/build/outputs/apk/release/app-release.apk
```

根目录中的 `MiaoMiaoMath-v1.0.0-release.apk` 是已有发布包；重新发布时建议按版本号重命名，例如：

```text
MiaoMiaoMath-v1.0.1-release.apk
```

## 8. 发布前检查清单

每次发布前建议按顺序执行：

```powershell
$ErrorActionPreference = 'Stop'
.\scripts\sync-android-assets.ps1
npm run sync:android:check
npm test
```

Android 发布还需要额外执行：

```powershell
$ErrorActionPreference = 'Stop'
Set-Location .\android
.\gradlew.bat assembleRelease
```

检查项：

- Web 页面能打开首页和练习页。
- 数学、语文、英语、科学都能生成题目。
- 选择题答案不是固定 A。
- Android assets 与 Web 端资源一致。
- APK 能安装并进入练习。
- 本地学习记录、错题、宠物奖励功能可正常保存。

## 9. 回滚方式

Web 部署回滚：

- 恢复上一版静态资源目录。
- 或使用 Git 回退到上一版 commit 后重新部署。

Android 回滚：

- 重新安装上一版 APK。
- 如果只是 Web 资源问题，回退 Web 资源后重新执行 `sync-android-assets.ps1` 并重新打包。

Git 回退应优先使用新提交修复，避免直接改写远端历史。确需历史回退时，先备份当前分支。
